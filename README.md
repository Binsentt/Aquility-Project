# 💧 Aquility Mobile App

Aquility is a mobile application designed to simplify water quality testing and monitoring. The application allows users to record, manage, and monitor water quality test results through a clean and user-friendly mobile interface.

---

## 📱 Features

- Water quality testing records
- Test history and monitoring
- User authentication
- Secure data management
- Mobile-friendly interface
- Fast and responsive performance

---

## 🛠️ Tech Stack

### Mobile
- React Native
- Expo

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Tools
- Git
- GitHub
- VS Code

---

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/Aquility.git
```

### Install dependencies

```bash
npm install
```

or

```bash
pnpm install
```

### Start the application

```bash
npx expo start
```
