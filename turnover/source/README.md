# AQUALITY Source Package

This folder is a safe handoff view of the application source relevant to the verified AQUALITY client and backend workflow.

## Included source areas

- `components/` — camera, scanner, map, and UI components
- `screens/` — navigation screens and result/history flows
- `services/` — API, export, GPS, calibration, and map logic
- `context/` — auth/session state and app data
- `backend/` — application server, validation, analysis engine, and schema implementation

## Usage

Use the repository itself as the authoritative source of truth; this package is a curated subset suitable for safe transfer or review without private data.
